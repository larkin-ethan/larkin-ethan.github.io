Filings IQ — cited Q&A over SEC filings

A retrieval-augmented generation (RAG) app that answers questions about public companies using their 10-K and 10-Q filings from SEC EDGAR. The goal: every answer cites the exact passage it came from, and the app says "I don't know" when the filings don't support an answer. I've just started building it, so the list below is the plan.

  • Adding a company's ticker pulls its filings from SEC EDGAR's free API right away, and a daily job checks for new 10-Ks and 10-Qs
  • Splits filings into their sections (like Risk Factors and MD&A) without breaking financial tables apart, embeds them with Voyage AI, and stores them in Postgres with pgvector
  • Hybrid search that combines keyword and vector results, reranks them, and filters by company and fiscal year
  • Answers written by Google Gemini, with a checker that confirms every quote and number actually appears in the passage it cites
  • An 80–100 question test set, including questions the filings can't answer, that measures retrieval accuracy, answer correctness, faithfulness and whether it declines when it should; numeric answers are double-checked against the SEC's XBRL financial data
  • Retrieval quality is re-tested automatically on every change; FastAPI and Streamlit app, deployed on Fly.io with Neon Postgres
  • Built with the assistance of AI: Claude explains each design choice, and I write the key parts myself

Drop a Bop — music rating app

A private music-sharing app for friend groups and coworkers: every weekday each member shares one song, everyone rates the week's songs from 0 to 10, and when ratings lock on Sunday the results, stats and leaderboard are revealed. It moved my group's song-of-the-day spreadsheet into a real app, history included.

  • Song search through Apple's catalog, links from Apple Music, Spotify or YouTube Music, and an in-app YouTube player
  • Anonymous until results: who shared each song stays hidden while the week is open
  • History calendar, taste stats, leaderboards, achievements, comments, saved songs and no repeat songs
  • Front end hosted on Cloudflare Pages; back end serverless on AWS (Lambda, API Gateway, DynamoDB, Cognito), defined as code with AWS SAM and built to run at extremely low cost
  • Around 1,000 automated tests (unit, database, browser at phone and desktop sizes) plus guardrails that block unsafe changes
  • Built with the assistance of AI: I wrote the specs and guardrails, ran Claude Code agents to build it, and required automated tests and CI to pass on every change

Loom — AI resume tailor

A career vault and AI resume tailor. You log your work history, skills and projects once; when you find a job posting, Loom checks it against your vault and rewrites your resume around it, using only what you've actually logged.

  • Analyze a posting for matches and gaps, generate a tailored resume with a note on why each line is there, then export to PDF or Word with an optional cover letter
  • Prompt design and grounding: each AI call has its own system prompt and structured output, and every AI-written line must link to a real vault entry, checked on the server before it's shown
  • An anonymized AI second opinion scores each resume the way a hiring manager would
  • Pipeline board, job search and mock interviews; Stripe plan tiers and Supabase Postgres with row-level security
  • Built with the assistance of AI: I wrote the spec, guardrails and the AI system prompts, ran Claude Code agents to build it, and made tests and CI mandatory for every change

Direction-Finding Drone

My UT Dallas senior design project, sponsored by L3Harris: an autonomous drone that finds a specific radio signal and turns to face it. I was on the 5-person computer science team, working alongside a 6-person computer engineering team, in fall 2024.

  • A software-defined radio (SDR) captures the signal, and a Jetson Nano computes its FFTs in close to real time
  • FFTs run in parallel on the Jetson Nano's GPU, written in C++ and CUDA on Linux
  • A live spectrogram plots the FFT results and updates in real time as the signal changes
  • Our team delivered the real-time signal processing that the drone's direction finding builds on
  • My part: I helped design the original FFT processing in MATLAB and wrote CUDA FFT code when it was converted to C++ and CUDA. I also led the switch to unified memory so the CPU and GPU share the same data instead of copying it back and forth, which cut computation time, and helped connect the FFT output to the live spectrogram

Banking Application

A banking web app built with a team of five for a Data and Applications Security class at UT Dallas. Users create an account, sign in, and send money to each other, and the point of the project was keeping every one of those steps secure.

  • Users sign up, sign in and are given a token when they log in
  • Transfers between users update both balances and are refused if the sender doesn't have enough money
  • Transaction details are encrypted with 2048-bit RSA keys, so they aren't sent in plain text
  • Passwords and Social Security numbers are hashed before they're stored, and SSNs are checked for a valid format
  • Next.js (React) and TypeScript frontend with form validation, and a Python / Django backend
  • My part: I created the project, set up automatic deployment to Azure Static Web Apps with GitHub Actions, connected the Django backend to a PostgreSQL database hosted on Microsoft Azure, and designed the database models for members, bank accounts and transactions

Portfolio Peak — portfolio diversification website

A stock portfolio site built with a team of five for a Database Systems class at UT Dallas. Users enter the stocks they own and how they want their money split between large, mid-size and small companies, and the site suggests how many shares of each to buy to get there.

  • PostgreSQL database storing users, their stocks, target splits, cash balances and past suggestions
  • A price bot updates every stock to the current market price once a minute and calculates one-week and five-year growth
  • React dashboard with a pie chart of the portfolio's current split and a table of stock stats
  • Django REST API with token sign-in; the frontend, backend and price bot each run in their own Docker container
  • My part: I created the project and wrote its first piece, a Python script that pulled live ETF prices and worked out how many shares to buy to keep an IRA balanced. I also designed the first sign-up and sign-in pages and worked on the price bot
